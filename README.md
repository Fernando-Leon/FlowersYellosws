# Flor 3D 🌻

Una flor amarilla en 3D hecha solo con HTML, CSS y JavaScript. Gira en los tres ejes (X, Y, Z) cuando mueves el teléfono, usando el sensor de orientación (`deviceorientation`).

- **iPhone:** toca "Activar sensores" y acepta el permiso.
- **Android:** los sensores se activan solos.
- **Recalibrar:** toma la posición actual del teléfono como el punto de partida.
- Sin sensores (o en computadora) puedes girar la flor arrastrando con el dedo o el ratón.

> El sensor solo funciona con HTTPS, así que úsala desde GitHub Pages, no abriendo el archivo local.
